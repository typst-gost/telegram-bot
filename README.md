# Typst GOST RAG Telegram Bot

Telegram-бот для ответов на вопросы по системе вёрстки Typst и пакету modern-g7-32 (оформление по ГОСТ 7.32-2017) на основе векторной базы знаний docs_vector_db.

## Возможности

- Ответы на вопросы через команду /help <вопрос> в личных сообщениях и групповых чатах (включая темы форумов супергрупп).
- Поддержка Telegram Rich Messages (Bot API 10.1+): заголовки, таблицы, списки, цитаты и блоки кода.
- Прямые ссылки на документацию: под сообщением формируются инлайн-кнопки со ссылками на соответствующие разделы сайта https://typst-gost.ru, а номера источников [1], [2] в тексте автоматически преобразуются в ссылки.
- Гибридный поиск по LanceDB (векторный поиск + FTS BM25 с ранжированием RRF и доменными синонимами).

## Требования

- Python 3.12 или выше
- Пакетный менеджер uv
- Токен Telegram-бота от @BotFather
- API-ключ Polza AI (POLZA_AI_API_KEY)
- Локальная векторная база docs_vector_db из репозитория typst-gost/website

## Установка

1. Клонируйте репозиторий и перейдите в каталог проекта:

git clone <url-вашего-репозитория>
cd typst-gost-bot

2. Установите зависимости проекта с помощью uv:

uv sync

## Загрузка и обновление базы знаний (docs_vector_db)

Проиндексированная база LanceDB находится в каталоге docs_vector_db репозитория github.com/typst-gost/website.

### Способ 1. Встроенный скрипт синхронизации (не требует Node.js)

Скрипт скачивает архив ветки main репозитория, извлекает директорию docs_vector_db и атомарно обновляет локальную папку:

uv run sync-docs-db

При необходимости можно переопределить репозиторий, ветку или путь:

uv run sync-docs-db --repo typst-gost/website --branch main --target docs_vector_db

### Способ 2. Через tiged (требует Node.js)

npx tiged typst-gost/website/docs_vector_db docs_vector_db --force

Для последующих обновлений базы достаточно повторно запускать любую из указанных команд.

## Настройка окружения

Создайте файл .env:

cp .env.example .env

Параметры:

- BOT_TOKEN — токен бота от @BotFather.
- POLZA_AI_API_KEY — API-ключ к сервису Polza AI.
- POLZA_BASE_URL — базовый URL API (по умолчанию https://polza.ai/api/v1).
- RAG_EMBEDDING_MODEL — модель для получения эмбеддингов (по умолчанию qwen/qwen3-embedding-8b).
- RAG_CHAT_MODEL — модель для генерации ответа (по умолчанию deepseek/deepseek-v4.1-flash-1017).
- DOCS_DB_PATH — путь к каталогу векторной базы (по умолчанию docs_vector_db).
- DOCS_BASE_URL — базовый адрес сайта документации (по умолчанию https://typst-gost.ru).
- RATE_LIMIT_SECONDS — задержка между запросами от одного пользователя (по умолчанию 3.0 секунды).
- LOG_LEVEL — уровень логирования (INFO, DEBUG, WARNING).
- LOG_FILE — путь к файлу логов (необязательно).

## Настройка приватности в @BotFather

Если бот добавляется в группы:
1. Выполните команду /setprivacy в диалоге с @BotFather.
2. Выберите созданного бота.
3. Установите значение Disable, если требуется, чтобы бот реагировал на команду /help <текст> без обязательного упоминания имени бота (@имя_бота).

## Запуск

uv run typst-gost-bot

## Использование

- /start — приветственное сообщение со ссылкой на сайт документации и примерами запросов.
- /help какие параметры есть у реферата — поиск по базе и генерация ответа со ссылками на документацию.
- /help как отключить автоматическую статистику в реферате
- /help как указать соисполнителя из другой организации
