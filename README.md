# Typst GOST Telegram Bot

Telegram-бот для ответов на вопросы по системе вёрстки Typst и пакету `modern-g7-32` (оформление по ГОСТ 7.32-2017) через централизованный сервис `ai-gateway`, с автоматическим рендерингом Typst-кода и `.typ`-файлов.

## Возможности

- Работа с AI через `ai-gateway` (RAG, TopicGuard, модели LLM и системные промпты управляются централизованно на стороне шлюза):
  - в личных сообщениях — потоковый ответ (`sendRichMessageDraft`) и сохранение истории диалога в `ai-gateway` (профиль `telegram_private`);
  - в группах и форумах — независимые ответы по команде `/help <вопрос>` (профиль `telegram_group`).
- Поддержка Telegram Rich Messages (Bot API 10.1+): заголовки, таблицы, списки, цитаты, блоки кода и встроенные изображения рендера.
- Локальный рендеринг блоков `typst` и файлов `.typ` с помощью CLI-компилятора `typst`:
  - при отправке кода пользователем возвращаются отрендеренные страницы или примечание с ошибкой компиляции и кнопкой «Исправить»;
  - при редактировании сообщения пользователем рендер автоматически обновляется;
  - кнопка «Исправить» вызывает эндпоинт `/api/v1/assistant/fix` (профиль `telegram_fix`) и рендерит исправленный код;
  - в ответах ассистента блоки `typst` компилируются автоматически.

## Требования

- Python 3.12+
- `uv`
- Установленный CLI-компилятор `typst`
- Развёрнутый сервис `ai-gateway` (локально или на удалённом сервере, адрес задаётся в `AI_GATEWAY_URL`)
- Токен Telegram-бота от `@BotFather`
