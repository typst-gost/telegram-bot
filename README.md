# Typst GOST RAG Telegram Bot

Telegram-бот для ответов на вопросы по системе вёрстки Typst и пакету modern-g7-32 (оформление по ГОСТ 7.32-2017) с автоматическим рендерингом Typst-кода и `.typ`-файлов.

## Возможности

- Ответы на вопросы через команду `/help <вопрос>` в личных сообщениях и групповых чатах (включая темы форумов супергрупп).
- Поддержка Telegram Rich Messages (Bot API 10.1+): заголовки, таблицы, списки, цитаты, блоки кода и встроенные изображения рендера.
- Автоматический рендеринг блоков `typst` и файлов `.typ`:
  - при отправке кода пользователем возвращаются отрендеренные страницы или примечание с ошибкой компиляции и кнопкой «Исправить»;
  - при редактировании сообщения пользователем рендер автоматически обновляется;
  - в ответах RAG блоки `typst` компилируются автоматически: успешные рендеры добавляются в сообщение, а фрагменты с ошибками пропускаются без вывода ошибок;
  - при превышении лимита вложений на сообщение отправляются страницы до лимита и добавляется предупреждение.
- Поддержка пакетов из Typst Universe с локальным кэшированием.
- Использование ассетов документации `compile_assets` при компиляции и передача списка доступных ассетов в промпт модели.
- Кнопка «Исправить» при ошибке компиляции: запуск RAG LLM с контекстом исходного кода и текста ошибки, вывод исправленного кода и его мгновенный рендер в том же сообщении.
- Прямые ссылки на сайт https://typst-gost.ru в сносках [1], [2] и кнопках под ответом.

## Требования

- Python 3.12 или выше
- Пакетный менеджер `uv`
- Установленный CLI-компилятор `typst` (доступный в `PATH` или по пути из `TYPST_BIN`)
- Токен Telegram-бота от `@BotFather`
- API-ключ Polza AI (`POLZA_AI_API_KEY`)
- Локальная база `docs_vector_db` и ассеты `compile_assets` из репозитория `typst-gost/website`

## Установка

1. Установите `typst` CLI (например, через пакетный менеджер ОС или релизы GitHub) и убедитесь, что команда `typst --version` работает.
   Для корректного рендера документов по ГОСТ 7.32 рекомендуется установить шрифт Times New Roman или указать каталог со шрифтами в `TYPST_FONT_PATH`.

2. Клонируйте репозиторий и перейдите в каталог проекта:

git clone <url-вашего-репозитория>
cd typst-gost-bot

3. Установите зависимости:

uv sync

## Загрузка и обновление базы знаний и ассетов

Векторная база и ассеты для компиляции находятся в репозитории `github.com/typst-gost/website` (`docs_vector_db` и `public/docs/compile_assets`).

### Способ 1. Встроенный скрипт синхронизации (не требует Node.js)

Команда скачивает архив ветки `main` и атомарно обновляет локальные каталоги `docs_vector_db` и `compile_assets`:

uv run sync-docs-db

Дополнительные флаги при необходимости:

uv run sync-docs-db --db-only
uv run sync-docs-db --assets-only
uv run sync-docs-db --repo typst-gost/website --branch main

### Способ 2. Через tiged (требует Node.js)

npx tiged typst-gost/website/docs_vector_db docs_vector_db --force
npx tiged typst-gost/website/public/docs/compile_assets compile_assets --force

## Настройка окружения

Создайте файл `.env`:

cp .env.example .env

Основные параметры:

- `BOT_TOKEN` — токен бота от `@BotFather`.
- `POLZA_AI_API_KEY` — API-ключ к сервису Polza AI.
- `POLZA_BASE_URL` — базовый URL API (по умолчанию `https://polza.ai/api/v1`).
- `RAG_EMBEDDING_MODEL` — модель для эмбеддингов (по умолчанию `qwen/qwen3-embedding-8b`).
- `RAG_CHAT_MODEL` — модель генерации ответа (по умолчанию `deepseek/deepseek-v4.1-flash-1017`).
- `DOCS_DB_PATH` — путь к каталогу векторной базы (по умолчанию `docs_vector_db`).
- `DOCS_BASE_URL` — базовый URL сайта документации (по умолчанию `https://typst-gost.ru`).
- `COMPILE_ASSETS_DIR` — путь к каталогу ассетов (по умолчанию `compile_assets`).
- `TYPST_BIN` — путь к исполняемому файлу `typst` (по умолчанию `typst`).
- `TYPST_CACHE_DIR` — каталог кэша пакетов Typst Universe (по умолчанию `.typst_cache`).
- `TYPST_FONT_PATH` — дополнительный каталог шрифтов для компилятора (необязательно).
- `TYPST_COMPILE_TIMEOUT` — лимит времени одной компиляции в секундах (по умолчанию `15.0`).
- `TYPST_COMPILE_PPI` — разрешение PNG при рендеринге (по умолчанию `144`).
- `TYPST_MAX_SOURCE_CHARS` — максимальный размер исходного кода в символах (по умолчанию `50000`).
- `MAX_RENDER_ATTACHMENTS` — лимит прикрепляемых изображений на одно сообщение (по умолчанию `10`).
- `RATE_LIMIT_SECONDS` — минимальный интервал между запросами от одного пользователя в секундах (по умолчанию `3.0`).
- `LOG_LEVEL` — уровень логирования (`INFO`, `DEBUG`, `WARNING`).
- `LOG_FILE` — путь к файлу логов (необязательно).

## Настройка приватности в @BotFather

Чтобы бот в группах видел сообщения с блоками кода `typst` и файлы `.typ` (а не только команды с `@имя_бота`):
1. Выполните команду `/setprivacy` в диалоге с `@BotFather`.
2. Выберите вашего бота.
3. Установите значение `Disable` (или выдайте боту права администратора в группе).

## Запуск

uv run typst-gost-bot

## Использование

- `/start` — справка по работе с ботом и ссылка на сайт документации.
- `/help какие параметры есть у реферата` — поиск по документации и генерация ответа с авторендером приведённых примеров кода.
- Отправка блока кода ` ```typst ... ``` ` или файла `.typ` — компиляция кода в изображения (или вывод примечания с ошибкой и кнопкой «Исправить»).
- Редактирование сообщения с кодом `typst` — автоматическое обновление рендера.
